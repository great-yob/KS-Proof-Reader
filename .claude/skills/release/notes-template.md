## 설치

처음 설치하는 경우 아래 **KS-AI-Editor-Setup-{ver}.exe** 를 받아 실행하세요.
이미 설치돼 있다면 앱을 실행하면 업데이트 안내가 자동으로 뜹니다.

> 서명되지 않은 설치 파일이라 Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄웁니다.
> **추가 정보 → 실행**을 눌러 진행하세요.

## 변경 사항

### 수정
- **사용자가 겪던 증상을 한 줄로** — 원인과 이제 어떻게 되는지를 한두 문장으로.

### 개선
- **무엇이 나아졌는지 한 줄로** — 필요할 때만.
